## Research question

Which service ratings and passenger characteristics best predict whether an airline passenger is satisfied, and does a random forest predict satisfaction more accurately than logistic regression?

Data: the Kaggle *Airline Passenger Satisfaction* survey (Bhat, 2022), 129,880 passengers.

---

## 1. Prerequisites (Windows and macOS)

You need **R (4.1 or newer)** and the packages listed below. **RStudio Desktop** (optional, https://posit.co/download/rstudio-desktop/) is also supported via `ca3.Rproj`.

### Install R

- **Windows:**
  1. Download and run the installer from CRAN: https://cran.r-project.org/bin/windows/base/ (or run `winget install RProject.R` in PowerShell).
  2. No `PATH` setup or Rtools installation is required when using `run.ps1`, `run.bat`, or RStudio — missing packages install automatically as precompiled binaries into your user library.
- **macOS:**
  1. Download and install the `.pkg` for your Mac (Apple Silicon `arm64` or Intel `x86_64`) from CRAN: https://cran.r-project.org/bin/macosx/ (or run `brew install --cask r` with Homebrew).
  2. For `make`, macOS includes it with Xcode Command Line Tools (`xcode-select --install` if not already installed).

### Automatic package setup

The runner automatically installs any missing packages (`caret`, `randomForest`, `car`, `e1071`, `psych`) from CRAN before the analysis starts. No separate package installation command is required.

To check or install packages without running the analysis:

- **Windows (PowerShell):** `.\run.ps1 -Check`
- **Windows (Command Prompt):** `run.bat --check`
- **RStudio Console:** `source("scripts/check_packages.R")`
- **macOS / Linux:** `Rscript scripts/check_packages.R`

## 2. How to run

Run all commands from the **project root folder** (takes about 1 minute).

### Option A: Using the platform launcher (easiest)

- **Windows (PowerShell):** run `.\run.ps1` (if PowerShell blocks local scripts on your machine, either run `powershell -ExecutionPolicy Bypass -File .\run.ps1` or allow local scripts once with `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`).
- **Windows (Explorer / Command Prompt):** double-click `run.bat` in File Explorer, or run `run.bat` in Command Prompt.
- **macOS:** run `./run.sh` from Terminal. If needed, make it executable once with `chmod +x run.sh`.

### Option B: Using RStudio

1. **Open the project at the repository root:**
   - Double-click `ca3.Rproj` in File Explorer (Windows) or Finder (macOS), **or**
   - In RStudio, select **File → Open Project...** and choose `ca3.Rproj` in the project root folder.
   - This automatically sets RStudio's working directory to the project root (confirm `ca3` appears in the project switcher at the top-right; do not create a new project inside a subfolder).
2. **Run the full pipeline** (missing CRAN packages install automatically on first run):
   - **Using the GUI:** In the **Files** pane (bottom-right), open `scripts/run_all.R` and click **Source** (top-right of the editor, or press `Ctrl+Shift+S` on Windows / `Cmd+Shift+S` on macOS).
   - **Using the Console:** Run:
     ```r
     source("scripts/run_all.R")
     ```
3. **Run individual stages (`01` through `05`)** *(optional)*:
   - Open any stage script in `scripts/` and click **Source**, or run e.g. `source("scripts/01_data_preparation.R")` in the Console.
   - Scripts `02`–`05` read `.rds` files generated by earlier stages, so run `01` first (or run `run_all.R` once) before re-running later scripts individually.
4. **Inspect the outputs inside RStudio:**
   - Console output is mirrored live to `output/run_log.txt`.
   - Use the **Files** pane to open CSV tables in `output/tables/` and preview PNG charts in `output/figures/`.
5. **Troubleshooting:**
   - If you see *"Could not find data/airline_passenger_satisfaction.csv"*, the script was opened without the project active. Open `ca3.Rproj` or choose **Session → Set Working Directory → To Project Directory**, then run again.

### Option C: Using the Makefile

```bash
make run
```

*(On Windows, use `run.bat` instead of `make`.)*

### Option D: Using Rscript directly

From a terminal (`macOS` Terminal or `Windows` PowerShell / Command Prompt with R on `PATH`):

```bash
Rscript scripts/run_all.R
```

You can also run the stages one at a time in order (`01` through `05`), for example `Rscript scripts/01_data_preparation.R`.

**To check the results without running anything**, open `output/run_log.txt`, which records the output of every section from the last run.

## 3. Files in `data/`, `scripts/`, and `output/`

### `data/`

| File                                   | Purpose                                                              |
| :------------------------------------- | :------------------------------------------------------------------- |
| `airline_passenger_satisfaction.csv` | Raw Kaggle passenger satisfaction survey (129,880 rows, 24 columns). |
| `data_dictionary.csv`                | Column definitions and value scales for the raw survey.              |
| `url.md`                             | Link to the original Kaggle dataset page.                            |

### `scripts/`

| File                          | Purpose                                                                                                                                                                                                                        |
| :---------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `01_data_preparation.R`     | Imports and renames raw columns, checks excluded variables (departure delay and Wi-Fi), removes `0` ("not applicable") ratings and missing delays, sets factor baselines, and creates the stratified 70/30 train/test split. |
| `02_assumptions.R`          | Runs pre-model logistic regression assumption checks on the training set: outcome balance, continuous outliers, skewness/normality, categorical cell counts, Spearman correlations, and empirical log-odds linearity plots.    |
| `03_logistic_regression.R`  | Fits `model_1`, `model_2`, and `model_3`, compares AIC/BIC, checks VIFs and Cook's distance, writes assumption and odds-ratio tables, and validates `model_2` on the held-out test set.                                |
| `04_random_forest.R`        | Fits the 201-tree random forest on the training set, records out-of-bag and test-set confusion matrices, and ranks predictor importance.                                                                                       |
| `05_compare_and_forecast.R` | Compares both models on the test set, runs McNemar's test, forecasts satisfaction probabilities for nine devised passenger profiles, and benchmarks them against similar test passengers.                                      |
| `run_all.R`                 | Master runner that executes Scripts `01` to `05` in isolated environments and saves all section headings and results to `output/run_log.txt`.                                                                            |
| `ensure_packages.R`         | Helper sourced by every script to create a writable user library if needed and automatically install any missing CRAN packages (as precompiled binaries on Windows).                                                       |
| `check_packages.R`          | Standalone check/installer that verifies all five required R packages are available without running the analysis pipeline.                                                                                                 |
